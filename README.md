# CaanLoad

通用 CAN / CAN FD 总线负载估算工具。直接在浏览器打开 `index.html`，无需安装依赖或启动服务。场景保存在当前浏览器的 localStorage；“恢复初始场景”会重置为通用演示配置。

## 计算原理

计算方法参考用户提供的 [RoboMaster CAN 总线负载率文章](https://bbs.robomaster.com/article/557395)及其关联的帧位数计算表。工具分别计算每个设备的 TX 和 RX，再将同一物理总线上的占用相加。

设数据长度为 `D` 字节，仲裁速率为 `Rnom` bit/s，数据段速率为 `Rdata` bit/s，帧频率为 `f` Hz，每次发送事件中的帧数为 `n`：

```text
帧时间 t = 对应帧位数 / 对应阶段速率
单方向占用率 Udir = Σ(t × f × n)
总线占用率 Ubus = Utx + Urx
平均帧数/ms = Σ(f × n) / 1000
```

占用率是 0 到 1 的比例，页面以百分比显示。最小/最大占用分别使用最小帧位数和最坏帧位数估算；页面显示的折中值是两个占用率的算术中点，不是对实际位模式的统计平均。

## 经典 CAN 帧位数

标准 ID 的最小/最大估算采用文章关联表。扩展 ID 按该表中的总位数估算。`floor(x)` 表示向下取整。

```text
标准 ID：
  Bmin = 47 + 8D
  Bmax = 49 + 8D + floor((8D + 16) / 5)

扩展 ID：
  Bmin = 64 + 8D
  Bmax = 75 + 8D

帧时间：t = B / Rnom
```

例如标准 ID、8 字节帧：`Bmin = 111 bit`，`Bmax = 129 bit`；扩展 ID、8 字节帧：`128–139 bit`。动态填充位数量与帧内容有关，因此使用区间表示。

## CAN FD 帧位数

CAN FD 分开计算仲裁段 `A` 与数据段 `P`。标准 ID 表达式来自文章关联表；扩展 ID 使用代码中的近似估算。

```text
标准 ID 仲裁段：Amin = 28，Amax = 31

标准 ID 数据段：
  Pmin = 8D + 28， 当 1 <= D <= 2
  Pmin = 8D + 32， 其他 D
  Pmax = Pmin + floor((Pmin - 1) / 5)

扩展 ID 仲裁段：Amin = 49，Amax = 57

扩展 ID 数据段：
  Pmin = 8D + 32， 当 D <= 16
  Pmin = 8D + 37， 当 D > 16
  Pmax = Pmin + floor((40 + 8D) / 4) - 8
```

```text
FD 无 BRS：t = (A + P) / Rnom
FD 有 BRS：t = A / Rnom + P / Rdata
```

标准 ID、16 字节 CAN FD 帧按表估算为仲裁段 `28–31 bit`、数据段 `160–191 bit`。无 BRS 时两个阶段都按仲裁速率发送；有 BRS 时仲裁段按 `Rnom`、数据段按 `Rdata`。文章关联表中的纯 FD 示例对仲裁段的速率处理与正文描述不完全一致，本工具按实际输入的仲裁速率计算。

扩展 ID CAN FD 没有文章原表可逐项对照，按代码估算，结果属于近似值。文章表没有 0 字节 FD 帧，代码以字段公式外推。此类结果应作为规划估算，并用设备抓包或更完整的帧级模型校准。

## 频率、分组与边界

- `每次帧数`表示一次发送事件实际提交的帧数。例如组控一帧控制四台电机，TX 计 1 帧；四台电机分别回包则 RX 计 4 帧。
- 两种包在 1 kHz 循环中奇偶交替时，每种包的频率为 500 Hz、每次 1 帧。总负载等价于每毫秒发送 1 帧；平均帧数/ms 不表示任意具体 1 ms 窗口的瞬时峰值。
- 握手回包预设令 RX 频率跟随 TX 请求频率；固定回包预设的 TX 和 RX 频率独立。预设频率可修改，只是起始值，不代表设备固定能力。
- 模型不包含仲裁等待、发送相位、错误帧、重传和任务抖动，也不推断控制器邮箱或软件队列容量。配置应按实际发送事件分组，并为错误重传和突发流量留余量。
- 80% 是规划经验提示线，不是 CAN 协议硬上限。示例：1 Mbps 经典 CAN、标准 ID、8 字节帧按最坏 129 bit 计，80% 时间预算约 800 μs，可容纳约 6 帧/ms 的 TX+RX 总量；实际 TX 批量还需扣除同期 RX 和其他流量。

## 初始配置与预设

初始场景包含三路通用示例总线：CAN1、CAN2 为 1 Mbps 经典 CAN，CAN3 为 1 Mbps CAN FD 无 BRS。每条总线有两个 100 Hz 示例节点。协议预设包括 DJI 3508 一拖四、DJI GM6020、达妙 MIT 握手回包、LK 固定频率回包及 CAN FD 16 字节节点；所有预设的频率和帧数均可编辑。
