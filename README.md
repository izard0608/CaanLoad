# CaanLoad

通用 CAN / CAN FD 总线负载估算工具。直接在浏览器打开 `index.html` 即可使用，无需安装依赖或启动服务。场景保存在当前浏览器的 `localStorage`；点击“恢复初始场景”可恢复通用演示配置。

## 计算原理

计算方法参考 [RoboMaster CAN 总线负载率](https://bbs.robomaster.com/article/557395)及其关联的帧位数计算表。工具先分别计算每个设备的 TX、RX 占用率，再汇总同一物理总线上的占用。

设数据长度为 `D` 字节，仲裁速率为 `Rnom` bit/s，数据段速率为 `Rdata` bit/s，帧频率为 `f` Hz，每次发送事件中的帧数为 `n`：

```text
帧时间 t = 对应帧位数 / 对应阶段速率
单方向占用率 Udir = Σ(t × f × n)
总线占用率 Ubus = Utx + Urx
平均帧数/ms = Σ(f × n) / 1000
```

占用率取 0 到 1，页面以百分比显示。最小值和最大值分别使用最小帧位数与最坏帧位数估算；折中值是两者的算术平均值，不代表实际位模式的统计平均。

## 经典 CAN 帧位数

标准 ID 的最小值和最大值采用文章关联表；扩展 ID 按该表中的总位数估算。`floor(x)` 表示向下取整。

```text
标准 ID：
  Bmin = 47 + 8D
  Bmax = 49 + 8D + floor((8D + 16) / 5)

扩展 ID：
  Bmin = 64 + 8D
  Bmax = 75 + 8D

帧时间：t = B / Rnom
```

例如，标准 ID 的 8 字节帧为 `111–129 bit`，扩展 ID 的 8 字节帧为 `128–139 bit`。填充位数量取决于帧内容，因此结果用区间表示。

## CAN FD 帧位数

CAN FD 分别计算仲裁段 `A` 和数据段 `P`。标准 ID 使用文章关联表中的表达式；扩展 ID 使用代码中的近似公式。

```text
标准 ID 仲裁段：Amin = 28，Amax = 31

标准 ID 数据段：
  Pmin = 8D + 28， 当 1 <= D <= 2
  Pmin = 8D + 32， 其他 D
  Pmax = Pmin + floor((Pmin - 1) / 5)

扩展 ID 仲裁段：Amin = 49，Amax = 57

扩展 ID 数据段：
  Pmin = 8D + 32， 当 D <= 16
  Pmin = 8D + 37， 当 D > 16
  Pmax = Pmin + floor((40 + 8D) / 4) - 8
```

```text
FD 无 BRS：t = (A + P) / Rnom
FD 有 BRS：t = A / Rnom + P / Rdata
```

标准 ID 的 16 字节 CAN FD 帧按表估算为仲裁段 `28–31 bit`、数据段 `160–191 bit`。无 BRS 时两个阶段都使用仲裁速率；有 BRS 时仲裁段使用 `Rnom`，数据段使用 `Rdata`。文章关联表中的纯 FD 示例对仲裁段速率的处理与正文描述不完全一致，本工具按输入的仲裁速率计算。

扩展 ID CAN FD 没有文章原表可逐项对照，结果按代码近似估算。文章表未列出 0 字节 FD 帧，代码按字段公式外推。此类结果用于规划估算，实际部署前应结合设备抓包或更完整的帧级模型校准。

## 频率、分组与边界

- `每次帧数`表示一次发送事件实际提交的帧数。例如，组控一帧控制四台电机时，TX 计 1 帧；四台电机分别回包时，RX 计 4 帧。
- 两种包在 1 kHz 循环中交替发送时，每种包的频率为 500 Hz、每次 1 帧。总负载等价于每毫秒发送 1 帧；平均帧数/ms 不代表任意 1 ms 窗口内的瞬时峰值。
- 握手回包预设中，RX 频率跟随 TX 请求频率；固定回包预设中，TX 和 RX 频率独立。预设频率可以修改，只是起始值，不代表设备的固定能力。
- 模型不包含仲裁等待、发送相位、错误帧、重传和任务抖动，也不推断控制器邮箱或软件队列容量。请按实际发送事件分组，并为错误重传和突发流量预留余量。
- 80% 是规划提示线，不是 CAN 协议硬上限。例如，1 Mbps 经典 CAN、标准 ID、8 字节帧按最坏 129 bit 计算时，80% 时间预算约为 800 μs，可容纳约 6 帧/ms 的 TX+RX 总量；实际 TX 批量还要扣除同期 RX 和其他流量。

## 初始配置与预设

初始场景包含三路示例总线：CAN1、CAN2 为 1 Mbps 经典 CAN，CAN3 为 1 Mbps、无 BRS 的 CAN FD。每条总线包含两个 100 Hz 示例节点。协议预设包括 DJI 3508 一拖四、DJI GM6020、达妙 MIT 握手回包、LK 固定频率回包和 CAN FD 16 字节节点；所有预设的频率和帧数都可以编辑。
